# 포켓몬 구구단

구구단 문제를 맞혀 야생 포켓몬의 체력을 깎고 몬스터볼로 잡는 어린이용 구구단 놀이예요.

**바로 하기: https://pokemon-gugudan.vercel.app**

## 놀이 방법

- 2단부터 9단 중 하나를 고르면 그 단의 포켓몬이 나타나요.
- 보기 4개 중 정답을 누르면 포켓몬의 체력이 줄어요. 틀린 문제는 나중에 다시 나와요.
- 체력을 모두 깎으면 포켓몬을 잡아서 도감에 남아요. 하나도 안 틀리면 별 3개!
- 힌트를 누르면 곱셈을 점으로 보여줘요.
- '섞어서'를 고르면 2단~9단 문제가 섞여서 나와요.

| 단 | 포켓몬 |
| --- | --- |
| 2단 | 피카츄 |
| 3단 | 파이리 |
| 4단 | 이상해씨 |
| 5단 | 꼬부기 |
| 6단 | 푸린 |
| 7단 | 이브이 |
| 8단 | 고라파덕 |
| 9단 | 잠만보 |

## 만들기

`index.html` 파일 하나로 되어 있어요. `main` 브랜치에 올리면 Vercel이 자동으로 배포해요.

팬이 만든 비공식 학습 놀이예요. 포켓몬은 Nintendo · Creatures · GAME FREAK의 상표입니다.
